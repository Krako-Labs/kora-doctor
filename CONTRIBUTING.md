# Contributing

KORA Doctor is intentionally small.

The most useful contributions right now are:

- AUDR traces that expose a false positive or missed optimization candidate
- small heuristic improvements with a concrete before/after example
- compatibility fixes for real AUDR emitters and adapters
- installation or CLI bugs

Please open an issue before adding a large dependency, framework, dashboard, hosted service, or generalized plugin system. The project is optimizing for a small, credible CLI first.
